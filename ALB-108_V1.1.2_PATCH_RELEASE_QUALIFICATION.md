## Root cause

The immutable `v1.1.1` release predates four production fixes now merged to
`main`: recovery validation for intentional photo reuse, execution-inspector
scroll restoration, explicit runtime revision provenance, and migration away
from Adobe's deprecated UXP dropdown widget. Shipping those fixes under the old
`1.1.1` package and build identity would create a false source-to-artifact
provenance claim.
